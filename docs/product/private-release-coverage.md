# Private release: required curriculum coverage

20 October 2026. **User-confirmed release breadth; implementation and educational approval remain outstanding.**

The user requires all categories in the [supplied catalogue](../research/references/2026-10-19-user-category-list.txt), repeated in the 20 October planning interview, before Adam's private daily-use release. Its detailed listed objective groups are the scope checklist, not optional examples. Earlier suggestions to launch only vocabulary/word classes or defer speech no longer define this release.

There are four product subjects. Redactiesommen belongs to Rekenen and is practised daily. The 12/7/5/10 headings are menu/product organization; canonical skills, practice formats and assessment facets must remain distinct.

## Completion contract

For each row below, create a versioned coverage record of every supplied objective group, initial number/language range, prerequisites, representations, accepted responses/rubric, content publication, independent assessment-family stock, explanations and progression permission. Approval of a screen does not complete a row.

Every required objective group must have usable published practice and a reviewed evidence strategy. Not every group must use autonomous scoring: the user chose **AI feedback with guardian review for open-ended judgments**. Until that review, no automatic mastery credit or unsupported score should be inferred. Decide how pending judgment affects completion/rewards before implementing those tasks.

Preserve approved two-attempt behavior for objectively scored questions. Extended writing/oral tasks require a separately reviewed revision/feedback contract; do not force arbitrary binary retries on a story or oral presentation.
