## Four cues and preserved behavior

**29 October question/answer hierarchy refinement:** the user requested clearer grouping without dominant cards. The shared `GuardianResultBrowser` now gives the prompt a quiet ivory surface, submitted attempts compact neutral borders, and the answer model a fine separator with secondary explanation text. Attempts flow side by side when space permits and stack in narrow containers. Existing disclosure controls, copy, exact values, reading passages and withheld solutions are preserved. The change applies to both the connected reference and saved results; student and historical classic previews remain unchanged. **Approved by the user on 29 October 2026**, with required adoption for future Guardian implementations. Follow the [shared pattern](guardian-visual-language.md#question-and-answer-details); see the ledger for executed checks.

| Cue               | Implemented presentation and host responsibility                                                                                                                                                                                               |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Location          | Persistent active navigation, one page heading, selected learner/context, return actions and focus restoration. Drafts survive navigation within the connected reference.                                                                      |
| Outcome           | Draft, pending, acknowledged success, error and uncertain response are distinct. Persistent `role=status` receipts describe changes; failures use `role=alert` and keep a retry path. Saved adapters confirm only acknowledged API outcomes.   |
| Reversal/recovery | Reference planning/profile changes expose working local undo. Saved review decisions, publication, withdrawal and browser revocation explain irreversible consequences and their real recovery path. Approval and publication remain separate. |
| Next step         | Receipts and empty states link to the next useful action or missing prerequisite. Operational details remain reachable without leading the main flow.                                                                                          |

The new presentation preserves original committed answers and every attempt, complete reading passages, distinct solved and weighted counts, normalized completed scores out of ten, and withheld scores/solutions where required for unfinished work. Withdrawal does not erase original work. No new scoring, evidence, mastery or educational approval rule is introduced. Existing identity, permission, recent-MFA, content version and publication controls remain host-owned.
